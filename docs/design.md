# TransLens — как это устроено и почему так

Задача: в AWS Cloud Quest (и подобных интерфейсах) половина текста живёт в видео, канвасе и
картинках — обычным выделением его не достать. Нужен перевод «по области экрана».

## Решения

**Область, а не текст страницы.** Снимаем вкладку через `chrome.tabs.captureVisibleTab`, режем
область на канвасе и распознаём OCR. Так работает и на субтитрах внутри `<video>`, и на подписях
внутри канваса.

**Оверлей прячется перед снятием.** `captureVisibleTab` фотографирует страницу вместе с
инжектированным DOM, поэтому рамка и затемнение убираются на время снятия (двойной `rAF` + 60 мс).

**Масштаб кропа считается по картинке.** `scale = image.width / viewport.width` — одинаково
корректно на Retina и при зуме браузера; `devicePixelRatio` не используется напрямую.

**OCR в offscreen-документе.** MV3 service worker не умеет `new Worker()`, а tesseract нужен
worker + wasm. Offscreen-документ (`chrome.offscreen`, reason `WORKERS`) — штатное место для этого.
tesseract.js и языковые данные лежат в `vendor/` — ни одного сетевого запроса.

**Предобработка важнее движка.** Тёмный интерфейс Cloud Quest: grayscale → авто-инверсия по
медиане яркости → растяжение контраста по перцентилям 2/98 → увеличение ×2 для мелкого текста.
Без инверсии OCR на тёмном фоне сыпется.

**Перевод — встроенный Translator API Chrome.** Бесплатно, офлайн, без ключей. Работает только в
secure context (https / localhost) и требует transient user activation при первой загрузке
языкового пакета. Поэтому прогресс (`Translator.create`) запускается прямо на `mouseup`, пока жест
«горячий», и живёт в MAIN world страницы (`window.__cqtTranslator`) — из offscreen/сервис-воркера
активации нет. В настройках есть кнопка, которая качает пакет из extension-страницы по клику.

**Короткий таймаут вместо ожидания.** Если пакет ещё качается, через 30 с панель говорит, что
делать, а не висит две минуты.

## Известные ограничения

- `$3` вместо `S3` на фирменном шрифте — лечится автоправкой AWS-терминов (в настройках, вкл. по умолчанию).
- DevTools, открытый на вкладке, ломает `captureVisibleTab` — в панели выводится понятная ошибка.
- Только активная вкладка и её видимая область (без скролла и фоновых вкладок).
- `file://` требует включённого «Разрешить доступ к файлам» в карточке расширения.
